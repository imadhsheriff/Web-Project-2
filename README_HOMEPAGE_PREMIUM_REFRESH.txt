TRAVELHUB HOMEPAGE PREMIUM REFRESH

This update refines the homepage hero, navigation bar, typography, photo framing, destination/package cards, and readable white text on dark image labels. The Ella train hero image is bundled locally at assets/images/ella-train-hero.jpg so the hero does not depend on an external image host. Existing PHP pages, database scripts, admin functions, and customer pages are preserved.

Run through WAMP/Apache and import database/travelhub.sql. For the supplied sample data, import database/travelhub_demo_data.sql after the schema file. The website has not been live-tested against your local MySQL instance in this environment.
